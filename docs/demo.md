# 五分钟展示流程

1. 展示三个图片工作流的输入、固定约束与输出，不先宣称全自动数字人。
2. 运行清单示例，查看8个唯一组合及planned状态，解释生成计划与实际成图的区别。
3. 提供自己有权展示的母版和文案，在可用图片工具中执行一小批。保存实际提示词、结果和质检，不用示意图冒充生成成果。
4. 选一张失败图解释检查发现了什么，修复后另存版本并重新检查。没有真实失败记录时标明模拟案例。
5. 用一份脱敏简历与JD运行第三方求职skill，展示经历证据如何对应岗位；说明该skill为开源集成。

记录表：输入版本 / 执行工具 / 实际产物 / 文案检查 / 视觉检查 / 人工审核 / 待解决问题。
