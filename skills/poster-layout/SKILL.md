# 图片版式生成

## 输入
读取本轮最终文案、尺寸、参考素材和风格要求。区分参考图的视觉风格与权威文案；当前明确文案优先，不能从旧图补入旧稿。缺少正文时不擅自新增内容。未指定尺寸可提出3:4并标明假设。

## 流程
1. 将输入拆为标题、正文、固定素材、允许变化项与禁改项。保留全文、数字、标点与特殊符号；仅调整排版换行。
2. 根据文案长度选知识卡、对比卡或大字报。传统简洁与精致插画是不同方向，按本次要求选择，不用装饰多少代替质量判断。
3. 先生成一张母版。保持标题正文层级、充足留白、手机阅读尺寸下的对比度。避免装饰遮字；长文案排不下时换版式，不删字凑版。
4. 精确固定的人像、Logo或包装优先使用用户授权原资产合成；不能把“模型尽量保持”说成像素不变。缺少合成工具则明确限制。
5. 逐字校对标题和全文，检查漏行、重复字、旧字残留、阅读顺序、边缘裁切。OCR只辅助定位，不能替代逐张查看。
6. 保存母版、原文与检查表。未经检查的母版不进入批量变体；改版另存新版本。

## 输出格式
- 母版文件与来源引用。
- 固定项、允许变化项、尺寸和风格说明。
- 文案核对、布局、素材一致性各项结果（通过／不通过／待核实）。
- 本轮未解决的问题。

## 执行与记录
使用当前环境已配置的图片生成或编辑工具，遵循该工具的调用说明。没有可用工具时只输出方案和未执行状态，不把提示词当作成图。记录实际工具、输入引用、输出路径和执行结果；不得记录密钥。请求结果未知时先找已有记录或产物，不盲目重复提交。

## 交付
交付文件、逐项质检结果、失败或待核实项。技术检查通过不等于业务审核通过；不虚构运行、审核、上传或交付记录。
