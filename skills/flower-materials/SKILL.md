# 花字素材生成

## 输入与优先级
读取最新需求表的分类、完整文案、目标、停产标记和视觉约束。按实际表头识别字段；历史记录只用于查重，不能覆盖新版需求。先过滤停止生产项，不因存在历史数量缺口而补产。
本轮数量、目标用途与输出尺寸缺失且影响执行时再询问。

## 生成与质检
1. 先列结构不同的候选样式，例如紧凑两行、票券、分段标签；同文案仅换颜色不自动算新样式。
2. 保留所有文字、符号和受保护词组。换行不能拆散用户指定词组；不得添加功效、承诺或宣传语。
3. 按当前风格设计字形和底衬。整句要有可读对比；装饰放在文字外围，不能替代笔画或覆盖文字。用户要求实色底衬时，描边不能代替底衬。
4. 使用真实透明PNG，保留有色底衬，检查alpha而不是棋盘格预览。全透明、白底冒充透明或明显裁字均不合格。
5. 按预期使用尺寸分别叠在亮、暗、复杂背景检查全文可读性、边缘光晕和留白。记录测试尺寸与背景；没有执行就标待检查。
6. 新图先进入临时产出区，技术质检完成后进入待审核。业务明确反馈后才改成已通过或不通过；不能用AI自评替代审核。
7. 修改另存版本，记录替代关系。保留历史素材；本次整理不自动授权删除、上传或更改线上审核状态。

## 素材库与计数
按 `图片/大类/子类/文案编号/审核状态/文件.png` 整理，状态为已通过、待审核、不通过。用稳定编号、相对路径、内容哈希、完整文案、版本与反馈证据关联台账，避免移动后失联。
分别统计本地生成、技术质检通过、实际送审和当前有效通过数量。反复送审同版本不重复累计。
累计送审版本数 = 当前通过 + 当前不通过 + 送审待审核 + 已移除；未送审候选不计入等式。
对外统计与内部明细分开，更新现有表格时保留模板格式。手动移动文件不会自动刷新统计，每次交付明确统计截止点。

## 字体与素材
实际使用字体文件时记录文件、来源和许可证。AI绘字不能证明使用了某种授权字体。公开示例使用自行提供或许可明确的素材。

## 执行与记录
使用当前环境已配置的图片生成或编辑工具，遵循该工具的调用说明。没有可用工具时只输出方案和未执行状态，不把提示词当作成图。记录实际工具、输入引用、输出路径和执行结果；不得记录密钥。请求结果未知时先找已有记录或产物，不盲目重复提交。

## 交付
交付文件、逐项质检结果、失败或待核实项。技术检查通过不等于业务审核通过；不虚构运行、审核、上传或交付记录。
